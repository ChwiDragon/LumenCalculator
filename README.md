# 루멘 카운터

오프라인 대전 카드게임 '루멘콘덴서'를 두 사람이 폰 한 대로 함께 쓰는 체력·토큰 계산기입니다.
폰을 테이블 가운데에 가로로 눕혀 두면 왼쪽은 1P, 오른쪽은 2P 화면이 됩니다.

- 캐릭터 18명의 시작 체력 · 손패 한도 · 토큰 · 특성을 자동으로 적용
- 데미지 · 회복 버튼(−600 ~ +200), FP(+ / − 와 −9 ~ +9 바로 입력), 캐릭터별 토큰과 특성 표시
- 30분 경기 시간, 10초 / 30초 카운트다운, 턴 표시, 서든데스
- 되돌리기와 게임 로그 (최근 10게임 보관, 지난 게임 이어하기, TXT 파일로 내보내기)
- 인터넷 없이 동작, 개인정보 수집 없음, 경기 중 화면 꺼짐 방지

## 사용법

### 화면 방향

앱은 가로 화면으로 고정되어 있습니다. **폰 윗부분이 왼쪽으로 가게** 눕혀서 테이블 가운데에 두면,
왼쪽(폰 윗부분)이 1P, 오른쪽(폰 아랫부분)이 2P입니다. 웹 버전은 폰을 세로로 들고 열어도 같은 방향의 가로 화면을 그립니다.

### 상단 메뉴

- **NEW GAME** 캐릭터 선택으로 (두 번 눌러 확인)
- **LOG** 기록 보기
- **SETTING** 설정 · 사용법 · 버전
- **UNDO** 마지막 행동 취소 (되돌린 직후 은은하게 빛나요)

### 캐릭터 선택

- **캐릭터 칸** 처음 누른 쪽이 1P, 두 번째가 2P (같은 캐릭터를 두 번 누르면 미러전)
- **1P SELECT / 2P SELECT** 지금 고를 차례
- **고른 캐릭터 칸 · 좌우 아래 캐릭터** 누르면 그쪽 선택 취소
- **↻** 1P · 2P 선택 모두 취소
- **GAME START** 둘 다 고르면 나타나요

### 체력

- **빨간 / 초록 버튼** 피해 / 회복
- **연달아 누르기** 체력 숫자 옆에 합계 표시
- **이름 옆 마름모** 체력 구간에 맞는 최대 손패
- **서든데스** 양쪽 체력이 모두 0이면 가운데에 나타나요 (양쪽 체력 1000 · FP 0)

### FP · 특성 · 토큰

- **+ / −** FP 1씩 조절
- **가운데 FP 숫자** 누르면 0
- **FP 버튼** 양쪽 −9 ~ +9 팝업 (가운데 ✕로 닫기)
- **특성 마크** 누르면 ON(밝게) / OFF(어둡게)
- **토큰 + / −** 개수 조절 (조건을 채우면 칸이 강조돼요)

캐릭터마다 다른 특성 · 토큰 규칙(자동으로 켜지는 특성, 시작 토큰 등)은 앱이 알아서 적용합니다.

### 타이머 · 턴

- **가운데 마름모** 탭 = 카운트다운 시작 / 처음으로
- **10 / 30** 카운트다운 길이
- **경기 시간** 탭 = 시작 / 일시정지, 길게 = 처음으로 (SETTING에서 바꾸기)
- **TURN** 탭 = +1, 길게 = −1

### 로그

- **로그 이름** 게임을 시작한 날짜 · 시간
- **로그 이름 길게(1초)** 그 게임 이어하기
- **새 게임 · 앱 다시 열기** 지금 로그 자동 보관 (최근 10개)
- **이어 누르기** 한 줄로 묶임 (되돌리기도 한 번에). 체력은 1초 안 · 피해와 회복을 합친 값(−500, +100 → 피해 −400), FP는 2초 안 · 1P와 2P 함께 결과값으로
- **되돌린 기록** 흐리게 "되돌림"으로 표시
- **ALL DELETE 길게(1초)** 모든 로그 삭제
- **TXT EXPORT** 모든 로그를 텍스트 파일로 저장

## 저작권 · 라이선스

- 루멘콘덴서는 야오니코믹이 개발하고 대원미디어가 유통하는 카드게임입니다. 이 앱은 플레이를 돕기 위해 만든 비공식 도구입니다.
- 캐릭터 일러스트의 저작권은 야오니코믹에 있으며, 허락을 받아 스토어 버전에만 사용합니다. 이 저장소에는 포함되어 있지 않습니다.
